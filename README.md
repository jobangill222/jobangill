# Jobanpreet Singh Portfolio

A personal portfolio built with the official Next.js App Router, React, and TypeScript.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production

```bash
npm run build
npm start
```

The project can be deployed directly to Vercel or any Node.js host that supports Next.js.
